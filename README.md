# Navdeep Kalsi — Industrial Automation & Robotics Portfolio

A responsive static portfolio website built around an industrial engineering / machine-design visual theme.

## What's improved in this version

- Consistent industrial visual language: dark graphite surfaces, engineering-green highlights, technical labels and clearer typography.
- A different machine / robotics photograph appears behind each major page section as the visitor scrolls. Project photos are also used in the section backgrounds so the visual theme stays relevant to the work.
- Project images are matched to their topics, use consistent display dimensions and include descriptive alt text. Project cards have clearer, more specific engineering titles and descriptions.
- Dedicated completed-course section with all 11 courses transcribed from the two Coursera screenshots.
- The Image Processing with Python certificate includes credential ID `3W6FDNT4R8QF` and its Coursera verification URL.
- LinkedIn profile link: https://www.linkedin.com/in/navdeep-kalsi-3511a6127/
- Responsive navigation, project filters, image lightbox, smooth scrolling, reduced-motion support and mobile layouts.

## Preview locally

Open `index.html` in a modern browser. Keep the `assets` folder beside it; do not move or rename individual images.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Open the repository used by your GitHub Pages site.
3. Replace the existing website files with the contents of `navdeep_portfolio_upgrade/` (including the complete `assets/` folder).
4. Commit and push to the branch/folder configured in GitHub Pages.
5. Wait for the Pages deployment to finish, then refresh your public site.
